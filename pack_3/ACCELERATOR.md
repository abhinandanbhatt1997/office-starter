This repository is a reusable accelerator.

- Standards.

- Checklists.
- Evaluation framework.
- Pre-flight tooling.
- Governance artifacts.
- Project instantiation tooling.

## What This Repository Is Not

This repository is not:

- A production application.
- A place for customer data.
- A place for project-specific secrets.
- A place for uncontrolled experimentation.
- A replacement for official project repositories.
