# Contributing to the Accelerator

**Document ID:** ACC-CONTRIB-001  
**Owner:** AI/ML Engineering  
**Status:** ACTIVE  

## Contribution Rules

1. Create a work item.
2. Create a branch from `main`.
3. Make the smallest useful change.
4. Update documentation.
5. Update CHANGELOG if behavior or structure changes.
6. Open a pull request.
7. Link the work item.
8. Request review.

## Pull Request Requirements

Every PR must include:

- Why the change is needed.
- What changed.
- What was tested.
- What risks remain.
- Whether documentation was updated.
- Whether templates were affected.
- Whether Pack 0/1/2 compatibility is preserved.

## Prohibited Changes

- Adding secrets.
- Adding production data.
- Adding project-specific business logic.
- Removing governance templates.
- Breaking existing pack structure.
