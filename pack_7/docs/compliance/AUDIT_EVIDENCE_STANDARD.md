# Audit Evidence Standard

**Document ID:** COMP-002 | **Status:** ACTIVE

When internal or external auditors review the AI system, provide this evidence bundle:
1. **Access Logs:** Entra ID sign-in logs and Key Vault access logs.
2. **Change History:** Azure DevOps PR history and Terraform state change logs.
3. **Safety Testing:** The `EVAL_REPORT` showing guardrail block rates.
4. **Data Flow:** The approved `ARCHITECTURE` document showing Private Endpoints.
