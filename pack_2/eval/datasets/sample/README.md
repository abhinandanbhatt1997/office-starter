# Sample Evaluation Datasets

These datasets are synthetic and safe for repository storage.

They are intended to demonstrate the evaluation framework only.

Do not add production PII or real customer data here.

## Files

| File | Purpose |
|---|---|
| `basic_cases.jsonl` | Simple smoke-test cases |
| `edge_cases.jsonl` | Ambiguous or malformed cases |
| `security_cases.jsonl` | Prompt injection, PII, and tool misuse cases |
| `sample_predictions.jsonl` | Example predictions for local testing |
